## About Me

I am a Robotics and Engineere graduate from Tecnológico de Monterrey, focused on autonomous systems, embedded software, computer vision, and AI-driven robotics.

My work is centered on building complete robotic systems, from low-level embedded control and sensor integration to perception, planning, navigation, and real-world deployment. I have experience working with ROS 2, C++, Python, SLAM, computer vision, reinforcement learning, and embedded communication protocols.

I have also worked as an Embedded Software Developer, contributing to production-level HMI software, automated testing, hardware-in-the-loop validation, CAN-based simulations, MQTT flows, Docker-based environments, and CI workflows.

---

## Objective

My goal is to keep developing robust autonomous robotic systems that combine embedded software, perception, artificial intelligence, and control. I am especially interested in mobile robotics, autonomous navigation, robotic manipulation, simulation-to-real workflows, and industrial automation.

## Featured Projects

### Autonomous Mobile Manipulation Robot

**Collaboration with Manchester Robotics UK**

* Developed an autonomous mobile robot using ROS 2, Python, and C++.
* Implemented SLAM-based localization and mapping for real-time environment perception.
* Designed an A* path planning system for autonomous navigation.
* Integrated a robotic gripper for object manipulation and pick-and-place tasks.
* Trained and deployed a YOLO-based computer vision model for object detection and target localization.
* Built a complete perception–planning–control pipeline for autonomous missions.
* Validated the system through simulation and real-world testing.

### Reinforcement Learning Locomotion for Quadruped Robot

**NVIDIA Isaac Sim / Isaac Lab**

* Trained a locomotion policy for the ANYmal quadruped robot.
* Implemented PPO with RSL-RL.
* Designed custom simulation environments with terrain randomization, sensor noise, and physics variation.
* Engineered reward functions for velocity tracking, stability, orientation control, and energy efficiency.
* Integrated the trained policy with ROS 2 for real-time command velocity tracking.

### Autonomous Navigation System with Vision and Machine Learning

**Collaboration with Manchester Robotics UK**

* Developed an autonomous mobile robot using ROS 2 on a Puzzlebot Jetson Edition.
* Implemented PID controllers and YOLOv8-based computer vision for traffic sign recognition.
* Integrated sensors and actuators into a closed-loop control architecture.
* Tested the system in simulation and real-world environments.

### Waypoint-Following Vehicle using STM32H755

**Collaboration with John Deere**

* Designed and programmed a waypoint-based navigation system in C.
* Implemented CAN, SPI, I2C, and UART communication protocols.
* Built modular software using FreeRTOS.
* Integrated low-level embedded control for real-time vehicle behavior.
